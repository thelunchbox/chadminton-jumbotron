# Chadminton Jumbotron

This project consists of three parts.
1. `main.js` the main process, which syncs between the displays
2. `index.html` is the controller, with a UI that allows for controlling what is shown on the scoreboard and what sounds are playing
3. `scoreboard/display.js` which is the display meant to be shown publicly

## Running

First, of course, run good ol' `npm i` to install all the dependencies.
Then you can start the project by calling `npm start`
